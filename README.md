# CoastVista3D

A 3D Graphics Simulation of Marine Drive, Cox's Bazar Using C++ and OpenGL.

## 1. Project Introduction

CoastVista3D is a 3D graphics simulation project based on Marine Drive in Cox's Bazar, Bangladesh. The project aims to represent the coastal landscape using computer graphics.

## 2. Project Objectives

- Create a 3D representation of Marine Drive.
- Visualize the road, beach, sea, hills and surrounding buildings.
- Understand 3D coordinate systems and object positioning.
- Develop a realistic coastal environment using C++ and OpenGL.

## 3. Technologies Used

- C++
- OpenGL
- Visual Studio Code

## 4. Scene Layout

The planned 3D scene will include:

- Marine Drive Road
- Beach
- Sea
- Hills and Mountains
- Surrounding Buildings

The arrangement will be planned using real visual references of Marine Drive.

## 5. Coordinate System

The proposed coordinate system:

- X-axis: Along the road.
- Y-axis: Across the coastal landscape.
- Z-axis: Vertical direction (height).

Object positions will be planned using this coordinate system.
